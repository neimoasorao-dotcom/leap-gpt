# UI/UX強化の構成と確認結果

## 実装

- `assets/ux-motion.js/css`：120/220/260/420msの共通Motion、ページのフェード、回答・カード・スターのフィードバック、可視領域の統計数値・棒・比率・折れ線の描画。固定操作列の祖先は変形しない。
- `assets/ux-shell.js/css`：4種のToast、範囲・一覧フィルター・復習分類・スロット編集／削除確認のSheet、ドラッグで閉じる操作、一覧のスター用SwipeとUndo、限定画面のPull to Refresh、同期中の構造別Skeleton。
- `assets/ux-search.js/css`：英語と意味の部分一致、最大7候補、最近の検索と頻度、IME、上下／Enter／Escape、スマホの候補位置調整。検索履歴は `leap_search_recent_v1` に分離し最大12件。

教材とスロットの保存スキーマは変更していない。採点・音声・保存を演出の完了まで待たせない。通常の自動保存ではToastを出さず、失敗した場合に通知する。同期の成功はPromiseの完了だけで判断せず `syncState.status` を確認する。

Pull to Refreshはスマホの記録・一覧・設定の画面上端に限定する。入力・横スワイプ・内側スクロール・Sheet・解答中・学習中とは競合させない。同期未設定ならローカル表示を再計算し「表示を更新」、設定済みなら同期後に更新する。ボタンによる同じ更新操作も残す。Skeletonは実際に通信待ちしているときだけ表示し、元の領域のサイズを保持する。

一覧の右スワイプでスターを追加、左スワイプで解除。75px以上かつ横方向が優勢な場合にだけ実行する。Undoは対象スロットと更新時刻を確認し、その後の変更を巻き戻さない。削除のSwipeは導入せず、セーブデータの削除には確認を残す。

## 再実行

開発環境にNode.js、Playwright、Chromiumがある場合：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory /workspace/leap-gpt
```

別のターミナルで：

```sh
node tests/ux-regression.cjs
node tests/ux-interactions.cjs
```

`LEAP_BASE_URL` で確認先を変更できる。相互作用テストは `CHROMIUM_PATH` も指定できる。本番用の依存ライブラリ・ビルド工程は追加していない。各テストは独立ブラウザの架空データと模擬通信を使い、利用者の記録・本物の同期先へアクセスしない。

## 確認したこと

- 8件の回帰ケースと2件の操作ケースが完了。教材3データは変更前とバイト単位で一致。
- 旧スロットの読み込みと再読み込み、version3 JSON往復、version1の取り込み、元スロットの保持。
- 一覧のクリック位置、同じユーザー操作内の読み上げ呼び出し、全7画面のナビゲーション。
- PC／スマホ × ライト／ダーク。検索候補、Sheetの範囲適用・名前編集・キャンセル、Escape・ドラッグ解除、復習分類。
- Swipe・Undo・キャンセル・縦移動・その後の変更保護。Pullの起動条件、実際のChromiumタッチ入力による更新。
- 同期の遅延中Skeleton、成功・失敗表示、容量不足の保存エラー。通信はテストで模擬した。
- reduced motionの初期設定・動的変更。320／390／1280pxで横にはみ出さず、操作終了後に不要なアニメーションが動き続けないこと。
- JavaScriptエラーなし。見た目はPC・スマホの実際のブラウザ描画画像でも確認。

## 確認できていないこと

iPhone実機のSafari、実音・音楽との同時再生、本物のGitHub認証を使う同期、端末実測の60fpsは未確認。ファイル直接起動はこのクラウドのブラウザポリシーが `file://` を拒否するため未検証。相対パスの通常のscript／CSSで構成し、ES Modulesや教材fetch、サーバー必須の仕組みには変更していない。

GitHub Pagesの公開処理と公開ページの直接アクセスは別の確認とする。クラウドの通信許可に公開ドメインが含まれない場合、公開処理の結果のみを確認し、公開ページ上での実機確認とは扱わない。
